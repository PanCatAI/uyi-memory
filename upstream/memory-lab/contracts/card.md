# 角色卡 2.0 格式（`characters/*.md`、设定页保存的版本）

一张卡是一份 Markdown。`# 名字` 开头，下面若干 `- 键：值` 元信息行，然后是 `## 节名` 分节。节名按前缀识别（`## 设定（作者写的，永远优先）` 也算「设定」）。
解析器是 `lib/card.mjs`，样例是 `characters/lan.md`。旧卡（只有 设定 / 说话方式 / 禁止）照样能解析，缺的节给空值。

| 节 | 写法 | 解析结果 | 去处 |
| --- | --- | --- | --- |
| 元信息 | `- id: lan`、`- 语言：中文`、`- 年龄：26`、`- 性别：女` | `meta` 对象 | 系统提示 |
| 设定 | `- 一条设定` | 字符串数组 `canon` | 系统提示；自述冲突检测 |
| 外貌 | 一段文字 | 文本 | 系统提示 |
| 核心性格 | `- 名：会怎么做` | `[{ name, how }]` | 系统提示 |
| 想要 / 需要 | 一段文字 | 文本 | 系统提示 |
| 价值观与底线 | 列表或一段文字 | 文本 | 系统提示 |
| 说话方式 | `- 句长：…`、`- 口头习惯：a；b`、`- 比喻库：a；b`、`- 绝不说：a、b`；其它行并入句长 | `{ length, habits[], metaphors[], never[] }` | 系统提示；漂移检测 |
| 对用户的初始看法 | 一段文字 | 文本 | 系统提示 |
| 知识边界 | 列表或一段文字 | 文本 | 系统提示 |
| 示例对话 | `<场合> 用户：… 岚：…`，一行一组 | `[{ occasion, user, reply }]` | 系统提示末尾 |
| 情绪模式 | `- 名：怎么说话｜动作：…`；第一条是默认情绪；名字唯一 | `[{ name, speech, action }]` | `mood` 节 |
| 过往 | `- [id] 标题｜正文｜关键词：a、b｜可说：初识` | `[{ id, title, text, keywords[], stage }]` | `lore` 节，按关键词检索 |
| 作息 | `- HH:MM–HH:MM｜地点｜做什么｜动作 目标 → 动作 目标（with: 物件）` | `[{ from, to, place, doing, steps: [{ name, target, args }] }]` | 生活循环（D1） |
| 秘密 | `- 正文｜揭示：挚友｜说明` | `[{ text, stage, note }]` | 关系阶段够了才进上下文（D5） |
| 成长弧 | `- 初识：…`（四档各一行） | `{ 初识, 熟悉, 亲近, 挚友 }` | `relationship` 节末尾 |
| 深度提醒 | `- 一条`，最多 3 条 | 字符串数组 | `reminder` 节 |
| 禁止 | `- 一条` | 字符串数组 | 系统提示 |

规则：

- 关系阶段只有四档：`初识`、`熟悉`、`亲近`、`挚友`。
- 作息的时间段可以跨午夜（`22:00–05:30`），合起来必须正好覆盖 24 小时、不重叠。
- 作息「动作」一列用 ` → ` 分开多个动作，每个动作是 `动作名 目标`（目标可省），末尾可带 `（with: 物件 id）` 作为 `args.with`。
- 认不出的节原样保留在 `extra`，不报错。
- 出错时抛中文错误，带行号，例如 `第 12 行：作息时间段重叠`。
