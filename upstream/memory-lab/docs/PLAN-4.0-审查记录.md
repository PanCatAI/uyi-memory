## 剩下的风险

- 盲玩是 n = 1，只能用来决定「做不做下一阶段」，不能说明普通玩家的留存。
- 裁判模型要异家族，前提是 Jonathan 在设置里配了第二家的 key；没配就只能做同家族判断，结论要打折扣（A 阶段先确认）。
- heard 事实放宽了一条记忆硬规则，等 Jonathan 确认。
- 3D 心情动画受造物台动作库的片段数量限制，缺的只能退回 Idle。
- 审查只看了代码快照，没有在 Mac 上跑真模型。
