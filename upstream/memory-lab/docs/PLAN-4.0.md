## 0. 现在在哪、问题是什么

### 0.1 四件事
1. **聊起来像采访**（3.1 的诊断，仍然成立）：你问她答，8 轮里没有一件事是在聊天时发生的。
2. **提示词里还住着岚**：`prompts/reply.system.md` 和 `prompts/idle.md` 里还有岚的例句（「小远。行。」「我不会去掀你被子」），intent 里有「拒绝、抱怨」，只要求「少用反问句」，self_claims 要求记下「对用户立的规矩」（自述检查反过来会维护这些规矩）。卡已经温柔了，提示词没跟上；宿主这边也没有任何检查管着「温柔」。
3. **银羽还没真正住进营地**：`scenes/camp.json` 的角色仍是 `lan` / `lan.md`，模拟和评测（`lib/simulate.mjs:55` 取第一个角色）量的都是岚。导入时第一个勾选的人会占用 `lan` 这个 id。有 10 个按岚旧卡原文写的测试在失败。
4. **营地只认第一个人**：导演、打赌、探路、事件文本、模拟、`session.tick` 都写死了 `characters[0]`，还有 `rules.mjs:115`、`scenarios.mjs:423`、`context.mjs:66`、`director.mjs:182`、`scene.mjs:73`、`public/app.js:67`，以及 4 个脚本里写死的 `'lan'`。导入能多选人物，但第二个人只是站在那儿。

### 0.2 文章说的方向
AI 陪伴正从「一个聊天框对一个角色」走向「一张地图上住好几个人，故事按事件和时间往下走」。Worldo：多角色各有身份、目标、隐藏背景，分层地点，故事事件，按段推进时间，世界回顾，对话里穿插旁白。Livo：角色有自己的目标和生活，用户不在时角色之间也会互动。我们已经有底子（宿主算的世界规则、作息、日记、按区域的感知、可忘可查来源的记忆），缺的是**温暖的情绪回报、每次见面的节拍、好几个人一起住**。

### 0.3 温柔不等于讨好
一项 3,075 人、五个实验的研究（R6）：多数人更喜欢讨好型 AI，因为「觉得被理解」；但三周后对现实人际交往更不满意。我们按 Jonathan 的要求做温柔、不顶嘴，同时守住**温柔要有内容**：她关心你，是因为记得你说过的事；她有自己的事、自己的看法（温和地说），也会请你帮个小忙；她不是每句都夸你、附和你。这一条用「空附和率」（7.5）来量。

### 0.4 Codex 报告怎么用
- 它的 P0（活动房间持久化、席位权限、双真人组局）是 TextWorker 的缺口。实验台是单人、SQLite 账本持久化、感知按角色过滤，不照搬它的排期。
- 拿来用的机制：**不替玩家说话和做决定**，推进时间不跨过玩家没做的决定（DreamGen；Worldo 自动跳时打断对话的反馈）；**正式说出口的和「再试一句」分开，重来后记忆一致**（DreamGen、AI Dungeon）；**记忆分层，玩家能看、能纠错、能补充**（AI Dungeon、Saylo、Tolan）；**后果看得见**（Friends & Fables）；**回顾只从玩家能知道的事里生成，并做非干扰测试**（报告的「安全事实投影」）。
- 拿来用的纪律：每个机制写清「玩家得到什么 / 代价 / 什么时候砍」；实验预先写死判定规则；没有证据的说法（「地图一定提留存」「角色越多越好」）不当前提。
- 采用它对文章事实的纠正：Worldo「8 角色 / 15 房间 / 10 事件」没有官方参数表证实；Character.AI 是申请破产保护、出售资产，平台仍在运行；猫箱 2200 万美元是商店内购估算的累计值。
- Livo 让角色会拒绝你，这一条不学（Jonathan 定了不顶嘴）；学它「角色有自己的目标、在往前走」。

## 1. 4.0 的设计

一句话：**她温柔、记得你、用行动照顾你；每次见面有起有落，发生的事看得见；营地里不只她一个人，你不在时故事也在往下走。**

### 1.1 四个阶段
| 阶段 | 内容 | 什么时候做 | 执行模型工作量（按以往速度估） |
|---|---|---|---|
| **A 打底** | A0 修测试并和卡解耦；A1 银羽住进营地；A2 提示词大扫除；A3 每人各聊各的，各有自己的卡；A4 删除修补；A5 每轮生成次数总上限 | 先做，不等盲玩 | 约 1.5 天 |
| **B 最小 4.0** | B1 一句旁白；B2 温柔检查；B3 开场带一件事、告别留钩子、推进时间前先问 | A 之后；做完跑 H2 和**第一次盲玩**（4 天） | 约 0.5 天 |
| **C 有内容的温柔** | C0 来源链和节拍预算；C1 关心线；C2 她准备的东西和你给她的东西；C3 她也需要被照顾；C4 她这阵子想做的事；C5 手帐；C6 换一句；C7 后果看得见；C8 会话小事；C9 留给你的小纸条；C10 关系的进展感；C11 心情驱动 3D、回来时她迎你 | 第一次盲玩过关以后；做完跑**第二次盲玩**（C 对比 B） | 约 3–4 天 |
| **D 大家一起住** | D1 世界认识每一个人；D2 插一句；D3 你不在时的小场景；D4 营地近况（多人版）；D5 7 天故事线；D6 两人剧本和真模型验收 | 第二次盲玩过关以后 | 约 3 天 |

为什么这样排：3.0 加了六套世界系统，盲评打平；换一张温柔的卡，Jonathan 马上觉得好多了。所以先做提示词和对话层（B），盲玩确认赢了，再加系统（C、D）。**「每人各聊各的、各有自己的性格」是 Jonathan 的明确要求，放在 A3 先做，不等盲玩**；插话、背后聊天、故事线这些「大家一起住」的玩法放到 D。

### 1.2 不做的事
多人联机、社区、Party Mode；创作者平台、UGC、漫画和视频生成；玩家选身份；让玩家用文字直接改世界的旁白模式；会拒绝你的角色、冲突型人设；换模型；24 小时全员自治（D3 只在有事时跑、按天限次）；语音（要做就单独立项，见待确认）。

## 3. 阶段 B：最小 4.0

### B1 一句动作或场景旁白（开关 `beat`）
- **文件**：`prompts/reply.system.40.md`（附录 A）、`contracts/llm-output.md`、`lib/llm-checks.mjs`、`lib/turn.mjs`、`public/chat.js`、新 `lib/beat.mjs`；新 `test/beat.test.mjs`。
- **做到什么**：回复 JSON 加可选 `beat`：一句第三人称、30 字以内的动作或环境描写。宿主只做三件事：超长截到第一个句号；beat 声称她拿 / 放 / 戴 / 坐 / 走到了什么而 action 里没有、世界里也不是这样，就丢（复用 `unbackedClaims`）；和最近 3 条 beat 太像（二字组 Jaccard ≥ 0.5）就丢。没有 beat 时不补宿主句子。界面上 beat 放台词上方，灰色斜体；🎬 标签只在右栏显示。beat 进账本（`char_said.payload.beat`），不进事实和自述。
- **验收**：mock：beat「她戴上了围巾」但没 wear → 丢；三句一样的 beat，第三句丢；超长截断；开关关着时提示词和输出都没有 beat。截图 `reports/b1-beat.png`。

### B2 温柔检查（开关 `warmth`）
- **文件**：新 `lib/memory/warmth.mjs`、`scenes/warmth.json`、`test/fixtures/warmth-negatives.json`；改 `lib/turn.mjs`、`lib/memory/idle.mjs`；新 `test/warmth.test.mjs`。
- **做到什么**：查最终送出的那句（A5），命中就带原因重说（占 A5 的总上限）：
  1. **反诘**：只认「难道……吗」「凭什么」「你就不能」「你还不 + 去 / 快 / 赶紧」。
  2. **一句多问**：问号 ≥ 2。
  3. **教训和数落**：词表「你应该 / 早说了 / 我说过 / 怎么老是 / 别瞎 / 少来」。
  4. **替你说完、替你决定**：主语「你」+ 叙述完成态（「你点了点头」「你答应了」「你心里一暖」「你接过了」），词表在 `warmth.json`。
  - **反例集至少 40 句，全部不能命中**，包括：「脚还疼吗？」「今天怎么样？」「你不是说脚疼吗？」「你还不睡呀？」「你怎么又给我带东西啦！」「你又走了这么远！」「你得先暖暖手」「你看那颗星」「你坐过来」。

## 7. H 评测：判定规则写死

### 7.1 先冻结，再跑
每次跑真模型评测之前，在 PROGRESS 里写死：开关清单、提示词哈希、种子、提交号、议程文件哈希、判定规则。跑完**所有结果都报告**。顺序：mock → 裁判校准 → H2 → H1。

**中性议程由本方案的作者（规划会话）在阶段 A 期间写好**，放 `scripts/agendas/neutral-*.json`，Jonathan 看一眼后冻结、记哈希，执行模型不改。

### 7.2 每次盲玩比的是什么
| 盲玩 | 「旧」那一路 | 「新」那一路 |
|---|---|---|
| 第一次（B 做完） | 3.0：现有 3.0 开关，4.0 开关全关，系统提示哈希和改动前一致 | 3.0 + A + B 的开关 |
| 第二次（C 做完） | 3.0 + A + B | 3.0 + A + B + C（不含界面类：C5、C6、C7、C9 的界面在两路都隐藏） |

两路都用银羽、同一张卡、同一个营地；每次重测换新的「今天的情况」卡和种子。

### 7.3 H2 模拟盲评（诊断，有一条底线）
- **组数**：3 个中性人设（好奇、冷淡、话多）× 4 个种子 = 12 组，每组两天三段（照 3.1 H2）。每个种子跑 2 次；**两次判同一边才算胜**，否则算平。关键轮用脚本原句，模拟用户温度 0.5。「累了一天」议程只算功能指标，不计胜负。
- **裁判**：用和对话模型**不同家族**的模型；左右各判一次，取一致的。先做 **A/A 校准**：同一路不同种子比 10 组，任一侧 ≥ 7/10 说明裁判有偏，停下修。另做一次「去掉旁白再判」：净胜 < 3 时，结论写「胜在旁白」。「她让人觉得被在意了吗」作为单独第二题。
- **底线**：H2 只做诊断，**不卡 H1**；唯一例外：新那路「负 − 胜 ≥ 3」（明显更差）就先停下修，不进盲玩。**没配异家族裁判时**，H2 全部只做诊断，底线也不用。
- **逐一去掉**（只做诊断，C 做完后跑）：以完整版为基准，分别去掉 B1、C1、C2、C8，各 20 组，报告每样去掉后输多少。
- **Jonathan 只读**每个人设第 2 天那一段，各 1 组（共 3 组），他的判断和裁判不一致时，以他为准并写进结论。

### 7.4 H1 盲玩（Jonathan 自己玩）
- **H1a 对话盲玩**：两路界面一致：C5、C6、C7、C9 的界面、C10 那行字、右栏「这次安排了哪几件」在两路都隐藏；旁白位置两路都留。每路一个存档，**4 天，每天两路各玩一次，顺序 ABBA 交替**，同一世界时间开局、同一张「今天的情况」卡。**盲玩存档关掉安静会话。**每天玩完回答：「今天哪个更想接着玩？」（选一个或「差不多」），再各打两个 1–5 分（想接着玩、被在意），再猜「这是哪一路」。
- **判定**（写死）：
  - 4 天里新那路 **胜 ≥ 3 且负 ≤ 1** → 过；**负 ≥ 2** → 不过；
  - 其他情况（比如 2 胜 0 负 2 平、2 胜 1 负 1 平、1 胜 0 负 3 平）→ **加测 2 天，只加一次**，6 天合计 **胜 − 负 ≥ 2 且负 ≤ 2** → 过，否则不过；
  - 8 次会话里他猜中版本 ≥ 7 次 → 结论标「非盲偏好」，此时还要 H2 没有触发底线才算过。
  - n = 1，这是「做不做下一阶段」的约定，不是统计结论。
- **H1b 公开试用**：界面类东西（手帐、换一句、后果图标、小纸条、升阶那行字、3D 迎接）不进盲玩，单独给他试 2 天，按第 6 节的砍法问他。
- **不过怎么办**：同一阶段最多修一轮再测一次；两次都不过，停下来和 Jonathan 商量，不自动进下一阶段。A3「各聊各的」不受影响。

### 7.5 指标（每次模拟都打出来）
新指标的判法写成逐句标注提示词 `prompts/turn-label.md`（异家族模型），先和 Jonathan 抽查的 20 句对照，**一致率 ≥ 80% 才用下面的阈值**，否则只报数不判。

| 指标 | 怎么算 | 目标 |
|---|---|---|
| 温柔命中率 | B2 四条在送出前的命中 / 全部句子 | 决定 B2 要不要重说 |
| 代言率 | B2 第 4 条在**最终送出**句子里的命中 | ≤ 1% |
| 温柔抽查 | 标注模型判 40 句 + Jonathan 抽 20 句：有没有呛、教训、代言、较真 | 补词表盲区 |
| 空附和率 | 她这句只附和、没给任何内容（自己的事、看法、提议、具体的关心）的比例 | ≤ 20% |
| 采访比 | 用户连续 ≥ 3 句问句、她一样东西都没还的次数 / 会话（标注模型判，不用模型自报的 intent） | ≤ 0.5 |
| 关心接得好 | 到期关心线里接得自然的比例；「打卡感」比例；「误关心」次数 | 打卡感 ≤ 10%；误关心每 10 次会话 ≤ 1 |
| 天气占比 | 专用天气词表（不含单字「天」），旁白和台词分开 | 台词 ≤ 25% |
| 花费和延迟 | 每 100 轮的调用、token、美元，前台后台分开；回复延迟 p95；同条件跑 3.0 基线 | ≤ 3.0 的 1.3 倍；p95 ≤ 1.5 倍 |

**节拍**（每次会话安排几件、同一种安排的重复率）在 H2 里算不出来（每组只有 3 段），另跑一个 7 次会话的长程模拟单独算：每次中间安排 ≤ 2 件，同一种安排重复率 ≤ 30%。

## 9. 待确认（Jonathan 看一眼，按重要程度排）

```
- 你有自己的看法，可以温和地说出来。他说错了你亲眼看到的事，可以轻轻提一次（「好像在物资角哦」）；他的感受、喜好和他说自己的事，你不纠正；他坚持，就顺着他。
- 可以请他帮个小忙（一次见面最多一次），他没接就算了。
- 关心要具体：记得他说过的累、疼、高兴的事。他说的是现实里的事（加班、考试），就照常关心。夸他就夸具体的事。
- 他一直在问你的时候，答完再给他一点东西：一件你今天的小事、一个想和他一起做的事，或者关心他一句。不要用「你呢」。
- 天气你已经说过两遍，就别再说，除非天真的变了。
- 打赌时你押的要和他不一样，押一样不算赌。
- 一句话最多问一个问题。同一件事问过一次他没接，就别再问了。
- 别用他的话开头，直接说你要说的。
```
