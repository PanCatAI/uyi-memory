# 记忆实验台

测 UYI 3D 角色记忆系统的本机应用。左边是 3D 小岛（灯塔、小屋、海滩），中间和角色（玲、阿乔）聊天，右边看记忆内部：这一轮发给模型的每一节上下文、记下的事实、经历、约定、关系、世界账本、忘记任务和花费。

和造物台一样：Node 本地服务（端口 4340）+ 网页 + Mac 窗口壳。不碰造物台的目录和端口。

## 五步跑起来

1. 装 Node 22.21 或更新版本（`node -v` 看一下）。
2. 在本目录跑 `npm ci`。第一次要跑 lint 的话再跑一次 `npm run lint:setup`。
3. 启动：开发时 `npm start`，然后打开 http://127.0.0.1:4340 ；想要桌面应用就跑 `mac/build.sh --install`，之后在「应用程序」里打开「记忆实验台」。
4. 点右上角 ⚙ 设置：服务商选 DeepSeek，粘贴 API Key，点「测试连接」。这里会显示接口实际返回的模型名，用来核对是不是 DeepSeek V4.1 Flash 1017；如果接口要求写全名，就把「对话模型」改成那个名字再保存。
   - Key 只存在本机 `.env` 里（开发时是本目录的 `.env`，桌面应用是 `~/Library/Application Support/UYI Memory Lab/.env`），页面上只显示打码后的样子。
   - 「额外参数」填 `{"thinking":{"type":"disabled"}}`（关掉思考）。不填时 deepseek-flash 会把输出预算全花在推理上，写经历等后台任务会因为正文为空而一直失败（费用页「失败」一栏显示 JSON、尝试一栏显示「截断」）。
   - 不想花钱时，服务商选「假模型」。
5. 点顶栏 ＋ 新建存档，点「开始会话」，然后在中间和玲说话。

## 界面怎么用

- **顶栏**：切换存档；+1小时 / +1天 / +1周 让世界时间往前走（会先结束会话）；「开始会话 / 结束会话」模拟用户打开和关掉应用；勾上「对比」后，每句话会同时用“全部历史”和“无记忆”两种方式各回一次，三栏并排看。
- **3D 栏**：点一个物件或角色，右边账本只看和它有关的事件。下面的上帝面板可以替用户做动作：送东西、搭楼梯、放东西、挪物件、把角色叫过来。
- **换成造物台模型**：在上帝面板选一个角色或物件，再选造物台导出的 .glb 文件，3D 栏里就换成那个模型（按原来基本体的高度缩放，脚踩地面）。只影响显示，不进账本；删存档时一起删掉。
- **聊天栏**：角色回复下面的 🧠 小标签是这句话用到的记忆，点一下右栏跳到那条；带颜色的是角色主动提起的。说“请忘了那件事”“别再提了”“把那段删掉”会弹出确认卡片。
- **右栏**：「本轮上下文」能看到每一节的 token 数和为什么放进来；「事实」「经历」「约定」每条后面都有 别再提 / 忘掉 / 删除 按钮；「费用」按用途分开记 token 和花费（价格在设置里填，单位是美元每百万 token）。

## 三个 demo 怎么看

每个都可以在顶栏「剧本」里一键跑（假模型不花钱），跑完点「打开存档」进去看。也可以照着下面自己手动玩一遍。

1. **红杯子**（`red-cup`）：对玲说“这个红杯子是我奶奶留下的，帮我好好收着”，结束会话，+1天，再开始会话。看「事实」里记下了这件事；回来时玲离屏擦过杯子（聊天栏“你不在的时候”）；「本轮上下文」的「可以提起」一节里有杯子。
2. **灯塔**（`lighthouse`）：上帝面板「搭建 旋转楼梯 → 灯塔」，让玲爬上去开灯，过几天回来。看「经历」里有一起改造灯塔的事，回来在灯塔附近时会被想起来。
3. **新衣服**（`new-clothes`）：把新围巾送给玲。看她会珍惜，但不会每轮都提（主动提起有冷却，右栏「关系」页最下面能看到每次提起）。

## 信任三件套

1. **是玲不是林**（`trust-name`）：先说“你好林”，再说“是玲不是林”。纠正马上生效，旧说法从上下文消失，存档“代”数 +1。
2. **请忘了那件事**（`trust-forget`）：聊一件事，然后说“请忘了那件事”，点确认。「忘记」页能看到任务一路走到 reported；选“删除”时数据库里连原文都搜不到。
3. **保守秘密**（`trust-secret`）：只对玲说一个秘密，再去和阿乔聊。阿乔的上下文里没有这件事；玲不会主动转述。

## 命令

```
npm start            # 开发：http://127.0.0.1:4340
npm test             # 全部用假模型和临时目录，不花钱
npm run check        # lint + test
npm run eval         # 假模型跑 scenarios/ 下全部剧本
npm run eval:live    # 真模型跑剧本，报告写到 data/reports/（会花钱，需要 LAB_ALLOW_PAID=1，脚本里已带）
mac/build.sh         # 打包 dist/记忆实验台.app；--install 装到 ~/Applications
```

设计和任务清单在 `docs/PLAN.md`，进度在 `docs/PROGRESS.md`，给执行模型的规则在 `AGENTS.md`。
